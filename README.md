# FinanSee

Dashboard financeiro desenvolvido para facilitar o acompanhamento de receitas, despesas, metas e hábitos financeiros por meio de uma interface simples, responsiva e interativa.

## Sobre o projeto

O FinanSee é uma aplicação web de controle financeiro que permite ao usuário registrar suas movimentações, acompanhar seu saldo, visualizar despesas por categoria e simular o alcance de metas financeiras.

O projeto foi desenvolvido com foco em organização de dados, experiência do usuário, responsividade e aplicação prática de JavaScript.

## Funcionalidades

- Dashboard com resumo financeiro
- Controle de receitas e despesas
- Cadastro de novas transações
- Exclusão de transações
- Pesquisa de transações
- Filtro por categoria
- Cálculo automático de saldo
- Cálculo de economia mensal
- Gráfico de despesas por categoria
- Score financeiro
- Insights baseados nos dados registrados
- Simulador de metas financeiras
- Persistência de dados utilizando LocalStorage
- Modo claro e escuro
- Layout responsivo para desktop, tablet e dispositivos móveis

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Chart.js
- LocalStorage
- Git
- GitHub
